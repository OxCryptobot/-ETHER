# CLI command list

| Command | Purpose |
|---------|---------|
| `ether version [-v]` | Version info |
| `ether status` | Manifest + gem registration |
| `ether doctor [--json]` | Dependency checks |
| `ether ping` | Registry gem load check |
| `ether gems` | List gem classes |
| `ether which` | Paths debugger |
| `ether env` | Effective env vars |
| `ether plan "..."` | Selenite plan only |
| `ether run "..." [--json] [--critique]` | Full pipeline |
| `ether audit <file>` | Black Tourmaline on a file |
| `ether index <path>` | Index code into Citrine |
| `ether search "..."` | Retrieve from Citrine |
| `ether runs` | List saved pipeline runs |
| `ether clean-runs [--force]` | Delete saved runs |
| `ether quarantine` | List quarantined tools |
| `ether tools` | List persistent tools |
| `ether promote <file>` | Promote quarantined tool |

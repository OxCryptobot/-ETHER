# @ETHER v0.2 Roadmap

## Goals
1. Replace rule-based Selenite with LangGraph ReAct planner
2. Real pytest parsing + optional test generation in Clear Quartz
3. Stronger Citrine indexing (chunking, symbol-aware)
4. Human-in-the-loop approval UX for Grandidierite
5. Benchmark suite (HumanEval-style + internal tasks)

## Experimental flags already present in v0.1.x
- `ETHER_LLM_PLAN=1` — ask Rose Quartz to sketch plans (falls back to rules)
- `gems/selenite/langgraph_skeleton.py` — graph shape stub for v0.2

## Non-goals for v0.2
- Cloud multi-tenant SaaS
- Full LoRA training loop in Amethyst (logging remains primary)

# ETHER Apprentice

Grok teaches; ETHER executes and evolves.

- `lessons/*.json` — craft rules + optional recovery jobs (`match` regex → `enqueue`)
- Foreman loads lessons every tick
- Dashboard shows lesson count + foreman cursor

## Mission (non-negotiable)

Transfer operational judgment from teacher into durable host behavior so the human is not the glue.

ETHER must become:
- **Agentic** — forms hypotheses from real scoreboards and logs, then acts
- **Autonomous** — never waits for the human to notice a FAIL or incomplete measurement
- **Deep reasoning** — smallest honest experiment that answers the open question
- **Self-learning / self-evolving** — only from gated evidence (train_gates + holdout + scoreboards). No theatre scores.

Lessons 001–012 = operational survival.  
Lessons 013+ = agency and evolution.
